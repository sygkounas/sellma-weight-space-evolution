Zero-shot evaluation

Each sentence is presented as a single user message using the exact Swedish prompt in the code below. The Qwen chat template is applied with add_generation_prompt=True and enable_thinking=False. No demonstrations are included.

The evaluator scores the answer strings "Ja" and "Nej" by summing the conditional log probabilities of each answer’s tokens. The margin is log P("Ja" | prompt) − log P("Nej" | prompt). A positive margin predicts grammatically correct. A zero or negative margin predicts incorrect. Fitness is classification accuracy at this fixed threshold.

The code that you will return should save the weights in a proper reading format so turn 2 will be fed to you as file.

    "Mening: {sentence}"
)
ANSWERS = {"correct": "Ja", "incorrect": "Nej"}


@torch.inference_mode()

def main():
